Cursor IDE Setup and GitHub Repository Task

 Overview
This repository contains the setup process for Cursor IDE along with the installation of Claude Code and Codex add-ons. The purpose of this task was to configure the development environment, create a GitHub repository, and document the complete process.

---

 Tools Installed

1. Cursor IDE
Cursor IDE was installed from the official website:

[Cursor IDE](https://cursor.com/?utm_source=chatgpt.com)

Cursor is an AI-powered code editor based on Visual Studio Code that supports AI coding assistants and extensions.

---
 2. Claude Code Add-on
The Claude Code extension was installed inside Cursor IDE through the Extensions section.

 Steps:
1. Open Cursor IDE
2. Go to **Extensions**
3. Search for **Claude Code**
4. Install the extension
5. Log in with the required account credentials

---

3. Codex Add-on
The Codex extension was also installed inside Cursor IDE.

 Steps:
1. Open Cursor IDE
2. Go to Extensions
3. Search for Codex
4. Install the extension
5. Log in successfully
